# Reference-camera character assets

Implements the actor portion of [ZURI-REFERENCE-FIDELITY](../ZURI-REFERENCE-FIDELITY.md). The original Concept 01 was supplied directly to the built-in `image_gen` tool as the camera, lighting, materials and human-proportion reference. No CLI fallback, external character pack or scripted image edit was used. Version 1 originals and metadata remain in the repository as historical assets; active imports use version 2.

## Identity and pose contract

The existing `characters-profiles.json` remains unchanged: fifteen stable IDs map to three generated adult anatomies with five garment variants each. This does not claim fifteen independently generated people. Blue garment coloring remains a runtime operation preserving source alpha and skin/hair colors.

Each source atlas contains three identity rows and six pose columns. Figure spacing is not an exact mathematical grid, so `characters-atlases-v2.json` supplies inspected individual crop rectangles rather than assuming equal-cell slicing.

Front columns: south idle, north idle, east idle, south stride A, south stride B, south seated. Back columns: north stride A/B, east contact/passing stride, north seated A/B. Side strides have visibly different knee/leg geometry; north and south phases alternate feet. West uses a horizontal reflection of the east artwork. No texture is rotated or skewed to fake the camera change.

`characters-directions-v2.json` declares rows in the existing API order: down=south/front, up=north/back, right=east/profile, left=reflected west/profile. All rows still expose seven slots: idle, two walking poses, seated A/B, read A/B. North has two generated seated hand poses; south aliases its single seated pose. Read aliases seated hands. **Only north/south seated art is supplied.** Unexpected side-facing seating falls back to a front pose; scene layout must select north/south for the four workstation pods. Angled lounge chairs remain a separate visual calibration limitation.

Runtime canvas size remains 128 × 224 with bottom-center anchor. Standing/walking silhouettes normalize to 208 pixels high, subject only to the 126-pixel maximum width, avoiding accidental height changes between generated poses. Seated art retains its proportion relative to that person's idle height. The scene owns depth-dependent displayed size, chair alignment and occlusion. The old isometric `−12` seated offset must not carry over as an assumed calibration.

## Inspection and evidence boundary

Read-only `System.Drawing.Bitmap.GetPixel` inspection confirms real transparency. Front: 1,041,146 pixels alpha 0; 74,389 alpha 1–15; 457,329 alpha ≥16. Back: 1,044,008 pixels alpha 0; 94,465 alpha 1–15; 434,391 alpha ≥16. Each sum equals 1,572,864 pixels. The apparent gradients in raw tool previews are residual RGB in transparent pixels, not an opaque runtime backdrop.

Crop bounds were inspected using alpha ≥64 within per-person regions to avoid low-alpha fringe bridges and neighboring poses. Runtime crops preserve the original PNG pixels; no image file was repainted, cut out or resized. The metadata and original hashes are covered by the actor asset test.

Static asset inspection confirms a raised camera, adult proportions, visible head tops, coherent fabric/lighting and distinct walking geometry. It does not establish final reference fidelity inside the room. The packaged composite still needs separate review of facing, head/hip/foot alignment, all sixteen chair anchors, foreground masks and walking transitions. Generated poses are compact frame animation, not skeletal interpolation or motion capture.

The focused actor checks pass: all fifteen IDs, three groups of five garment variants, both exact PNG hashes and RGBA dimensions, alpha counts, crop bounds, four semantic row mappings and valid distinct walking-pose references. The first two tests in the historical office test file still describe the old map compatibility fixture; they are not evidence for the new reference floor's reachability.
