## Asset boundary

The imported LICENSE-ASSETS and asset attribution distinguish LimeZu art from source MIT. The bundled license prohibits redistributing assets to others; upstream purchase evidence does not establish a transferable license for this fork. Zuri removes all three renderer LimeZu PNG atlases and both dependent maps, replaces them with original `zuri-office.svg`/`zuri-office.tmj`, and ships only that active office scene. Historical notices remain for provenance. Procedural avatar code from portraitArt.ts is MIT; display labels are team roles while identifiers remain stable. Build icons are original geometric Z marks generated by tools/generate-zuri-icon.py. Bundled font notices remain under assets/fonts.

Historical upstream blog/website/media are retained in source history and are not packaged product surfaces. The application About includes upstream credit. Package notices enumerate actual production dependency licenses; no paid asset license is inferred from the code MIT license.

In 0.2.0 the runtime office/characters/portraits use newly generated raster artwork under `src/renderer/src/assets/office-2.5d`, created with the built-in image_gen tool from the user's approved warm miniature-office direction. Prompts, unmodified source hashes and asset dimensions are recorded under `docs/design`. The old SVG tile map remains the navigation/anchor compatibility source; its pixel furniture is not rendered. No Munder Difflin/LimeZu raster art or zuri.ai image assets were used as generation references. The original procedural avatar implementation remains in source history; upstream MIT attribution is preserved.
